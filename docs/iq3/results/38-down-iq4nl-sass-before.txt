=== the loop arithmetic, from the source (kIq4nlBlocks = 20, SPLIT = 2) ===
8 U16 per inlined iq4nl_load_block call site
x 10 iterations per thread (20 blocks / SPLIT 2)
x 2 threads per row (SPLIT 2)
= 160 U16 loads per down row, today.
With the planar form: 1 LDG.128 per iteration -> 20 per row (8x fewer instructions, same bytes).
